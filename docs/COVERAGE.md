# WCAG 2.2 coverage

What accessready does about each of the 86 level A and AA success criteria in WCAG 2.2. Generated from `src/coverage.mjs` and axe-core 4.14.0; do not edit by hand.

| | Criteria | What it means |
|---|---|---|
| **Checked** | 36 | At least one automated check can fail a page on this. It never covers the whole criterion; the last column says what is left. |
| **Listed for review** | 8 | Nothing is judged automatically, but the HTML report lists exactly what a person has to look at. |
| **By hand** | 29 | No tool support. A person has to test it. |

No automated tool can establish that a site conforms to WCAG. This table is here so you can see what a clean run does and does not tell you.

| Criterion | Level | Status | What is tested automatically | What a person still checks |
|---|---|---|---|---|
| 1.1.1 Non-text Content | A | Checked | Images, icons and image buttons that have no description at all. axe-core: `aria-meter-name`, `aria-progressbar-name`, `image-alt`, `input-image-alt`, `object-alt`, `role-img-alt`, `svg-img-alt`. | Whether each description says what the image is for. The report lists every image with its description. |
| 1.2.1 Audio-only and Video-only (Prerecorded) | A | Flagged for a person | Audio players with no transcript, text version or lyrics mentioned in their section of the page. Video with no sound track (read from the media itself) and no transcript, description or described version near it. accessready: `audio-no-transcript`, `video-only-no-alternative`. | Whether the transcript or description matches what is heard or seen. |
| 1.2.2 Captions (Prerecorded) | A | Checked | Video elements with no caption track. YouTube and Vimeo players whose own caption list is empty (a failure), or holds only automatic speech-recognition captions (likely). axe-core: `video-caption`. accessready: `embed-no-captions`. | Whether captions are accurate and complete, not only present. |
| 1.2.3 Audio Description or Media Alternative (Prerecorded) | A | Flagged for a person | Video with sound that has no description track, no link to a described version and no transcript nearby. accessready: `video-no-audio-description`. | Whether the description or text alternative covers everything shown that is not said. |
| 1.2.4 Captions (Live) | AA | Flagged for a person | Live streams (media reporting an endless duration, YouTube live players) with no caption track and no mention of live captions. accessready: `live-no-captions`. | Whether live captions keep up and are accurate. |
| 1.2.5 Audio Description (Prerecorded) | AA | Flagged for a person | Video with sound that has no description track, no link to a described version and no transcript nearby. Video with sound that has a transcript nearby but no description track and no link to a described version. accessready: `video-no-audio-description`, `video-transcript-no-audio-description`. | Whether the audio description covers everything shown that is not said. |
| 1.2.6 Sign Language (Prerecorded) | AAA | Flagged for a person | At level AAA, video with sound and no sign language version mentioned near it. accessready: `video-no-sign-language`. | Whether the sign language version is complete and well interpreted. |
| 1.2.7 Extended Audio Description (Prerecorded) | AAA | Flagged for a person | Video with sound that has no description track, no link to a described version and no transcript nearby. Video with sound that has a transcript nearby but no description track and no link to a described version. accessready: `video-no-audio-description`, `video-transcript-no-audio-description`. | Whether pauses for extended description are long enough. |
| 1.2.8 Media Alternative (Prerecorded) | AAA | Flagged for a person | At level AAA, video with sound and no transcript or text alternative mentioned near it. accessready: `video-no-media-alternative`. | Whether the text alternative tells the whole story of the video. |
| 1.2.9 Audio-only (Live) | AAA | Flagged for a person | At level AAA, live audio streams with no live transcript or captions mentioned near them. accessready: `live-audio-no-alternative`. | Whether the live text alternative keeps up with the audio. |
| 1.3.1 Info and Relationships | A | Checked | Broken list, table and ARIA structure. axe-core: `aria-hidden-body`, `aria-required-children`, `aria-required-parent`, `definition-list`, `dlitem`, `list`, `listitem`, `td-headers-attr`, `th-has-data-cells`. | Whether headings, lists and tables are marked up as what they look like. The report shows each page's heading outline. |
| 1.3.2 Meaningful Sequence | A | By hand | Nothing. | Whether the reading order makes sense in places the tool flags. |
| 1.3.3 Sensory Characteristics | A | By hand | Nothing. | Instructions the tool flags: is there also a text label to go by. |
| 1.3.4 Orientation | AA | Checked | On a phone, pages that ask to be rotated, or hide almost all their text, when turned to landscape or back to portrait. accessready: `orientation-locked`. | Whether anything that does need one orientation (a piano app, a check deposit) is essential. |
| 1.3.5 Identify Input Purpose | AA | Checked | Invalid autocomplete values on form fields. axe-core: `autocomplete-valid`. | Whether each flagged field really collects the user's own details. |
| 1.3.6 Identify Purpose | AAA | By hand | Nothing. | Whether icons and regions are identified in a way assistive tools can adapt. |
| 1.4.1 Use of Color | A | Checked | Links inside text that differ from it by color alone. axe-core: `link-in-text-block`. | Color used as the only signal in charts and diagrams. |
| 1.4.2 Audio Control | A | Checked | Audio that plays by itself for more than three seconds with no way to stop it. Audio or video that a script started with sound before anyone used the page, longer than three seconds, with no browser controls and no pause, stop or mute button on the page. axe-core: `no-autoplay-audio`. accessready: `script-autoplay-audio`. | Audio started by scripts in ways the tool did not trigger. |
| 1.4.3 Contrast (Minimum) | AA | Checked | Text contrast on solid backgrounds. Text over images, gradients and video, measured from a screenshot with the text hidden. axe-core: `color-contrast`. accessready: `contrast-on-image`. | Text over an image that passes in some places and fails in others. The report lists each one with its measured range. |
| 1.4.4 Resize Text | AA | Checked | Pages that block pinch-zoom. Text whose size on screen stays the same when the page is zoomed to 200% and to 400% (sizes tied to the window, such as vw units). Text in a box that hides overflow and cuts the text off at 200% zoom, when it did not at 100%. Truncation the design asks for (ellipsis, line clamp) is left out. Lines of text drawn over other text at 200% zoom that were apart at 100%. axe-core: `meta-viewport`. accessready: `text-does-not-scale`, `zoom-clipped-text`, `zoom-overlapping-text`. | Whether everything stays readable at 200% in the places the tool flags. |
| 1.4.5 Images of Text | AA | Flagged for a person | The largest images on the page (up to six) read with OCR in English; images showing several words are reported. Images named or placed as logos are left out. accessready: `image-of-text`. | Whether flagged images of text are logos or essential. |
| 1.4.6 Contrast (Enhanced) | AAA | Checked | Text contrast on solid backgrounds at the enhanced ratio. At level AAA, text over images, gradients and video that clears 4.5:1 but nowhere reaches 7:1 (4.5:1 for large text). axe-core: `color-contrast-enhanced`. accessready: `contrast-on-image-enhanced`. | Text over images at the enhanced ratio, where the measurement is mixed. |
| 1.4.7 Low or No Background Audio | AAA | Listed for review | Nothing. | Whether speech in audio stands out from background sound by 20 decibels. |
| 1.4.8 Visual Presentation | AAA | Flagged for a person | At level AAA, pages that scroll sideways at 200% zoom in a full desktop window. At level AAA, paragraphs aligned to both edges. At level AAA, paragraphs whose longest line holds more than 80 characters, measured from the rendered lines. At level AAA, paragraphs of two or more lines with line spacing under 1.5 times the font size. At level AAA, consecutive paragraphs whose spacing, measured baseline to baseline across the gap, is less than 1.5 times their line spacing. accessready: `zoom-sideways-scroll`, `justified-text`, `long-lines`, `tight-line-height`, `tight-paragraph-spacing`. | Whether users can choose their own colors, and text width at 200%. |
| 1.4.9 Images of Text (No Exception) | AAA | Flagged for a person | The largest images on the page (up to six) read with OCR in English; images showing several words are reported. Images named or placed as logos are left out. accessready: `image-of-text`. | Whether flagged images of text are logos or pure decoration. |
| 1.4.10 Reflow | AA | Checked | Sideways scrolling at 320px wide, with the widest element named. accessready: `reflow`. | Content that is hidden or overlaps at 320px wide without causing a scrollbar. |
| 1.4.11 Non-text Contrast | AA | Checked | Text fields, dropdowns and text areas whose border and fill all stay under 3:1 against the background around them. Fields left with the browser's own look are exempt, as WCAG allows. Buttons and links that show only an icon (an inline SVG or an icon font glyph) whose colors all stay under 3:1 against the background behind them. accessready: `faint-field-border`, `faint-icon-control`. | Graphs and diagrams: does each part needed to understand them reach 3:1. |
| 1.4.12 Text Spacing | AA | Checked | Inline styles that force spacing. Text that is cut off once line, letter, word and paragraph spacing are widened to the values WCAG names. axe-core: `avoid-inline-spacing`. accessready: `text-spacing`. | Text that overlaps other content instead of being cut off. |
| 1.4.13 Content on Hover or Focus | AA | By hand | Nothing. | Popups the tool did not trigger. |
| 2.1.1 Keyboard | A | Checked | Scrollable regions and frames that the keyboard cannot reach. Controls with a click handler or an interactive role that the Tab key never reaches. Elements with a pointer cursor that Tab never reaches are noted for a person to try. Navigation menus are hovered, then the same is tried from the keyboard. Buttons that open something are pressed with Enter and Space as well as clicked. axe-core: `frame-focusable-content`, `scrollable-region-focusable`, `server-side-image-map`. accessready: `keyboard-unreachable`, `looks-clickable`, `hover-only-menu`, `keyboard-activation`. | Whether every custom widget (sliders, drag and drop, carousels) can be fully operated from the keyboard. |
| 2.1.2 No Keyboard Trap | A | Checked | An element that Tab and Shift+Tab cannot leave. accessready: `keyboard-trap`. | Traps inside widgets the walk did not open. |
| 2.1.3 Keyboard (No Exception) | AAA | Checked | Scrollable regions that the keyboard cannot reach. axe-core: `scrollable-region-focusable`. | Whether any function at all needs a mouse or touch. |
| 2.1.4 Character Key Shortcuts | A | By hand | Nothing. | Whether flagged shortcuts can be turned off or remapped. |
| 2.2.1 Timing Adjustable | A | Checked | Pages that redirect or refresh on a timer. Pages that reload or go to another address by themselves within 20 minutes, on a clock moved forward while nobody uses the page. Likely rather than failed when a warning came first. Pages that start saying the session has expired, or that the visitor was logged out, within 20 minutes of nobody using them, with no warning offering more time before that. axe-core: `meta-refresh`. accessready: `page-changes-by-itself`, `timeout-no-warning`. | Time limits after logging in, such as sessions that expire. |
| 2.2.2 Pause, Stop, Hide | A | Checked | Blinking and scrolling text. Video that plays by itself with no pause control. CSS animations that run for more than five seconds, and elements a script keeps moving for more than half a minute, with no pause or stop control nearby or for the whole page. Loading indicators are left out. Says whether the animation also stops when reduced motion is asked for. Parts of the page that switch what they show by themselves, still going after half a minute on a clock moved forward a second at a time, with no pause or stop button. Text that keeps changing by itself (tickers, feeds, counters) with no pause, stop or hide control. axe-core: `blink`, `marquee`. accessready: `moving-video`, `animation-no-pause`, `carousel-no-pause`, `auto-update-no-pause`. | Animations and moving content the tool did not see start. |
| 2.2.3 No Timing | AAA | Checked | Pages that reload or go to another address by themselves within 20 minutes, on a clock moved forward while nobody uses the page. Likely rather than failed when a warning came first. Pages that start saying the session has expired, or that the visitor was logged out, within 20 minutes of nobody using them, with no warning offering more time before that. At level AAA, pages that time out within 20 minutes even though they warn first, and whether the page says up front how long inactivity can last. accessready: `page-changes-by-itself`, `timeout-no-warning`, `timeout-warned`. | Whether timed steps are part of a real-time event. |
| 2.2.4 Interruptions | AAA | Checked | Pages that refresh or redirect by themselves. Pages that reload or go to another address by themselves within 20 minutes, on a clock moved forward while nobody uses the page. Likely rather than failed when a warning came first. At level AAA, popups and browser dialogs that open by themselves while nobody uses the page. axe-core: `meta-refresh-no-exceptions`. accessready: `page-changes-by-itself`, `timed-popup`. | Interruptions that arrive after logging in. |
| 2.2.5 Re-authenticating | AAA | By hand | Nothing. | Whether data entered is kept when a session runs out and the user logs in again. |
| 2.2.6 Timeouts | AAA | Flagged for a person | At level AAA, pages that time out within 20 minutes even though they warn first, and whether the page says up front how long inactivity can last. accessready: `timeout-warned`. | Whether users are told how long data is kept when inactivity can lose it. |
| 2.3.1 Three Flashes or Below Threshold | A | Checked | Three seconds of the screen recorded in Chromium and measured pixel by pixel against the WCAG general and red flash thresholds: more than three flashes in a second over more than a quarter of a 341 x 256 pixel area. accessready: `flashing`. | Flashing in video that was not playing during the audit. |
| 2.3.2 Three Flashes | AAA | Checked | Three seconds of the screen recorded in Chromium and measured pixel by pixel against the WCAG general and red flash thresholds: more than three flashes in a second over more than a quarter of a 341 x 256 pixel area. At level AAA, anything that flashes more than three times a second, however small. accessready: `flashing`, `flashing-small`. | Flashing in video that was not playing during the audit. |
| 2.3.3 Animation from Interactions | AAA | Flagged for a person | At level AAA, elements that still slide, scale or rotate (CSS transitions and animations, or scripts setting transforms) when the page is scrolled or hovered with reduced motion asked for. accessready: `motion-on-interaction`. | Motion triggered by interactions the tool did not perform. |
| 2.4.1 Bypass Blocks | A | Checked | Pages with no skip link, landmarks or headings to jump past repeated content. axe-core: `bypass`. | Whether the skip link lands on the main content. |
| 2.4.2 Page Titled | A | Checked | Pages with no title. Different pages that share a title are noted. axe-core: `document-title`. accessready: `duplicate-title`. | Whether each title describes its page. |
| 2.4.3 Focus Order | A | By hand | A dialog that opens without taking keyboard focus is noted. accessready: `dialog-focus`. | Whether the Tab order makes sense in the places the tool flags. |
| 2.4.4 Link Purpose (In Context) | A | Checked | Links with no text at all. axe-core: `area-alt`, `link-name`. | Whether each link says where it goes in its context. The report lists links such as "click here" and "read more". |
| 2.4.5 Multiple Ways | AA | By hand | Nothing. | Pages that are steps in a process, which are exempt. |

| 2.4.7 Focus Visible | AA | Checked | Every Tab stop is screenshotted focused and unfocused; if nothing on screen changes, it fails.
