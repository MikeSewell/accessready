# WCAG 2.2 coverage

What accessready does about each of the 86 success criteria in WCAG 2.2, levels A, AA and AAA. Generated from `src/coverage.mjs` and axe-core 4.14.0; do not edit by hand.

| Of the 86 WCAG 2.2 criteria | A | AA | AAA | All |
|---|---|---|---|---|
| Checked | 19 | 14 | 10 | 43 |
| Flagged for a person | 12 | 10 | 17 | 39 |
| AI review | 0 | 0 | 2 | 2 |
| Listed for review | 0 | 0 | 1 | 1 |
| By hand | 0 | 0 | 1 | 1 |

| Status | What it means |
|---|---|
| **Checked** | At least one automated check can fail a page on this. It never covers the whole criterion; the last column says what is left. |
| **Flagged for a person** | Automated checks find evidence of a failure, reported as a likely problem for a person to confirm. |
| **AI review** | Only the optional AI review (`--ai`, with a model or coding agent you choose) judges this. Its findings are for a person to confirm. |
| **Listed for review** | Nothing is judged automatically, but the HTML report lists exactly what a person has to look at. |
| **By hand** | No tool support. A person has to test it. |

AA is checked by default; `--level AAA` adds the AAA criteria. No automated tool can establish that a site conforms to WCAG. This table is here so you can see what a clean run does and does not tell you.
