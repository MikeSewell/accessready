# WCAG 2.2 coverage

What accessready does about each of the 86 level A and AA success criteria in WCAG 2.2. Generated from `src/coverage.mjs` and axe-core 4.14.0; do not edit by hand.

| | Criteria | What it means |
|---|---|---|
| **Checked** | 38 | At least one automated check can fail a page on this. It never covers the whole criterion; the last column says what is left. |
| **AI review** | 3 | Only the optional AI review (`--ai`, with a model you choose and pay for) judges this. Its findings are for a person to confirm. |
| **Listed for review** | 7 | Nothing is judged automatically, but the HTML report lists exactly what a person has to look at. |
| **By hand** | 10 | No tool support. A person has to test it. |

No automated tool can establish that a site conforms to WCAG. This table is here so you can see what a clean run does and does not tell you.
